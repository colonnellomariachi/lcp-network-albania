# Supplementary material

The article has two supplementary documents, in docx format:

- **S1** — `S1_PDI_validation.docx`: validation of the least-cost paths against
  the Via Egnatia and the corrected path deviation index.
- **S2** — `S2_sensitivity_analyses.docx`: sensitivity analyses.

They are deposited on Zenodo with the input data and the intermediate objects
of the pipeline: [ZENODO CONCEPT DOI].
